# Reporting a security problem

If you have found a way to make Marigold spend a note twice, take a note that is not yours, learn who holds a note, stop the network, or anything else that should not be possible, please tell us privately first.

## How

Write to **security@marigold.cash**. Say what you found, how to reproduce it, which version you were running (`marigold-cli --version`, or the version on the wallet's front note), and whether you have told anyone else.

Then send a short message to **@marigoldcash on Telegram** saying only that a security mail is waiting. Do not put the details in Telegram. The message is there so the mail is read the same day rather than whenever the inbox is next opened.

You will get a reply from a person, normally within two days, and a fix or an explanation as soon as there is one. If a fix ships, you are welcome to be named in the release notes, or not, as you prefer.

## What counts

Anything in this repository, the wallet image, the bridge, the faucet, and the website. The testnet is there to be broken: try what you like on it, and coins there have no value. Please keep proofs of concept off other people's wallets and machines, and do not run anything against mainnet once it exists.

There is no bounty programme. There is gratitude, credit, and a fast fix.

## What does not need this

Crashes, wrong balances, confusing prompts, and everything else that is a bug but not a hole go in a normal issue. If you are not sure which it is, use the mail.
