# Incident log

What went wrong on the public testnet, who saw it, why, and what closed it. One line per incident, newest last. Kept for P8.7's soak: the record that the network ran with outside participants and that every consensus-relevant incident left a regression test behind. "Seen by" is the founder, an outside tester, or the operator (me, running the hosts). **Consensus** marks incidents that touched the chain's validation or a node's state; those must carry a test. Wallet and host incidents are listed on the same footing because a tester cannot tell the layers apart, and neither should this log pretend to.

Outside testers have been on the network since 2026-09-07. The log was started on 2026-09-20 and backfilled from the commit history; the commit named in each row carries the full account.

## Open questions the log has raised

- A node still catching up can accept a transaction and lose it when the sync replaces the state it was validated against. The wallet now refuses to use such a node; whether the node itself should refuse `SubmitTransaction` while in IBD (the way it refuses block templates) is a node-side question for P8.4's drills.
- Pool-root divergences between nodes: none observed to date. The signers' quorum failure of 2026-09-19 was a signer bug, not a divergence: every node reported the same block once the targets agreed.
